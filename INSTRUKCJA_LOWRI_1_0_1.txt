AKTUALIZACJA NA GITHUB PAGES
1. Przed aktualizacją wykonaj kopię .wzm w dotychczasowym LOWRI / Wizmero.
2. Otwórz repozytorium kaborszkolenia-cell/wizmero-beta-test na GitHub.
3. Add file > Upload files, przeciągnij ZAWARTOŚĆ wypakowanego folderu (nie zip).
   Przekopiuj także cały podfolder assets. index.html w katalogu głównym.
4. Zatwierdź zmiany (Commit changes). GitHub Pages przebuduje stronę pod dotychczasowym URL.
5. W przeglądarce otwórz już istniejący adres https://kaborszkolenia-cell.github.io/wizmero-beta-test/.
6. Sprawdź nowy logo, brak ciemnego prostokąta, logowanie, bazę i ponowne uruchomienie.
7. Nie usuwaj aplikacji z telefonu i nie czyść danych przeglądarki.
